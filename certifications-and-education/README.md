## 📡 Cisco Networking Academy — CCNAv7 Curriculum

A two-course sequence aligned to the Cisco CCNA exam covering routing/switching, network security, wireless, and network services. Foundational for any SOC role — the analyst's job is monitoring traffic on networks like these.

| CCNAv7: Switching, Routing, and Wireless Essentials | CIS 161 | Highline College | Dec 2023 |

📄 [Official Cisco Networking Academy transcript](docs/learner_transcript.pdf)

### 📘 CCNAv7: Introduction to Networks (CIS 160)

Foundational networking knowledge: OSI and TCP/IP models, IP addressing and subnetting, Ethernet fundamentals, basic switching and routing, introduction to network security.

### 📗 CCNAv7: Switching, Routing, and Wireless Essentials (CIS 161)

16 modules of advanced switching, routing, and wireless concepts with hands-on labs in Cisco Packet Tracer:

#### 🔀 Switching Concepts & VLANs (Modules 1–4)
- Layer 2 switching — MAC tables, frame forwarding, CAM management
- Collision vs. broadcast domains
- Switch initial configuration and secure management access
- VLAN concepts, configuration, and trunking (802.1Q)
- Dynamic Trunking Protocol (DTP) and security implications
- Inter-VLAN routing — router-on-a-stick + Layer 3 switching
- Inter-VLAN routing troubleshooting

#### 🔁 Redundant Networks (Modules 5–6)
- Spanning Tree Protocol (STP) operation
- Rapid PVST+ configuration and troubleshooting
- EtherChannel — LACP and PAgP
- EtherChannel troubleshooting

#### 📡 Available & Reliable Networks (Modules 7–9)
- DHCPv4 — server, relay, troubleshooting
- DHCPv6 — stateless (SLAAC) and stateful
- HSRP — first-hop redundancy and failover
- Virtual IP / virtual MAC behavior

#### 🔒 Layer 2 Security & WLANs (Modules 10–13) ⭐ SOC-relevant
- Layer 2 attacks: **MAC flooding, VLAN hopping, DHCP spoofing, ARP poisoning**
- Switch defenses: **port security, DHCP snooping, Dynamic ARP Inspection (DAI)**
- WLAN concepts — 802.11, SSID, BSS, ESS
- Wireless security — **WPA2, WPA3,** enterprise auth
- WLAN configuration on Cisco wireless infrastructure
- Wireless troubleshooting

#### 🌐 Routing Concepts & Configuration (Modules 14–16)
- Routing tables, administrative distance, longest-prefix matching
- Static / default route configuration (IPv4 and IPv6)
- Floating static routes for backup paths
- Static and default route troubleshooting
- IPv6 routing configuration and verification
